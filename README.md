# YouTube Studio AI Image Swap

YouTube Studio の動画編集画面で、ページ上のAI生成画像候補を検出・保存し、ローカル画像を画像ファイル入力へ渡すためのManifest V3拡張です。

## 使い方

1. `chrome://extensions/` を開く
2. 「デベロッパーモード」をON
3. 「パッケージ化されていない拡張機能を読み込む」→ このフォルダを選択
4. YouTube Studioの編集画面を開く
5. 拡張ボタン → 「AI画像をスキャン」
6. 画像を選択 → 「選択画像をダウンロード」
7. 「画像を選択して差し替え」でローカル画像を選択

## 注意

YouTube StudioはSPAでDOM構造が変わるため、差し替え対象が通常のinput[type=file]でない画面では自動差し替えできません。その場合は選択画像を画面上に出して、Studio側のドロップ領域へドラッグするフォールバックを表示します。
